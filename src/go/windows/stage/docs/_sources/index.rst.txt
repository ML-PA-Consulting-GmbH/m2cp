L-IoT Documentation
====================

Introducing *L-IoT* by *ML!PA*, a full
ecosystem for cloud connected embedded devices. Our purpose-built
embedded hardware, Linux operating system and SDK make it simple to
build vertically integrated systems connecting existing infrastructure
to the cloud.
