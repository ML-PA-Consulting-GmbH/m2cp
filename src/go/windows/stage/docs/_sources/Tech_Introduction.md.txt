# Introduction
The architecture of L-IoT is designed to be vertically integrated, modular, customizable, and agnostic. It encompasses all layers from hardware to software, does not rely on external services, and allows each component to be selected and configured based on specific needs. The system is flexible, enabling users to adjust and tailor it to their requirements, and can operate across various environments without being tied to specific vendors or ecosystems.
